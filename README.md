# BAR Metal 4 contributor tap

```sh
brew tap yeojuny/bar-metal4
brew install bar-metal4-source
bar-metal4-source
```

Installs the October 19 source snapshot and contributor documentation, **not a playable app**. A native Metal 4 app cask is pending portable packaging, matching source and redistribution checks. See [the project](https://github.com/yeojuny/BAR-Metal4).

This tap does not modify the existing `yeojuny/bar` tap or its other BAR port. The formula verifies the immutable release archive with SHA-256. Formula and tap documentation are CC0-1.0; distributed source retains its original per-component licenses.
